Customer Assets for the JSM Portal

Your customers’ assets, right in the portal.

Customer Assets for the JSM Portal gives every customer a secure “My Assets” view in the Jira Service Management help center. They see exactly what is theirs. Every request they raise arrives with the right asset attached.

Start your 30-day free trial View documentation

Runs on Atlassian with no data egress. Built on Forge in Berlin, Germany.

Features

Asset self-service in the customer portal

Jira Service Management keeps your asset data in Assets. Customers can’t see that data in the portal. This app adds a secure self-service view, so customers can see, update and report the devices and licenses assigned to them.

See exactly what’s yours

Every customer gets a “My Assets” view with only the objects assigned to them. Every query is scoped server-side to the signed-in account. Access is default-deny, even against a manipulated frontend.

From asset to ticket in one click

Report a problem, ask a question, request a change or register a new asset. Each ticket uses your Jira Service Management request types and links the affected asset automatically. Agents never have to ask which device.

Edits you control

Per object type, choose read-only, direct edit or reviewed change requests. Low-risk fields update instantly. Sensitive ones go through a ticket your team approves.

Ownership that fits your schema

The owner can sit on the asset itself or on a linked record such as Employee -> User. Both work, and the app suggests the right path. You don’t need to restructure your CMDB.

Looks right in every language

English and German UI, following each user’s Atlassian profile language. Translate object-type and attribute names so “NB-HW-Pool” shows up as “Laptop”.

Setup that explains itself

A 4-step wizard with health checks and a one-click proposal that scans your site and fills in the configuration. A live preview shows your own portal while you map owners.

Product tour

See it in action

From the customer’s “My Assets” view to the asset-linked ticket in Jira. Every step is scoped to the signed-in user on the server.

Self-service portal

Every customer sees exactly their own assets

A secure “My Assets” view inside the customer portal, with search, filters and type tabs. The result set is scoped server-side with a default-deny model.

  • Default-deny security model
  • Search, filters and type tabs
  • Optional dashboard start view
Asset-linked requests

From asset to ticket in one click

Customers report a problem, request a change or ask a question straight from the asset. The affected asset is linked automatically. Agents see the reporter’s assets in the issue view.

  • Four processes: report, register, change, question
  • Direct edits or reviewed change requests, set per type
  • “Reporter Assets” glance for agents
Guided setup

A status panel and a one-click proposal guide the setup

Four plain-language checks come with fix buttons. An automatic suggestion scans your site and fills in the whole configuration. A verify button tests your Jira asset field end to end.

  • Setup wizard with contextual help
  • One-click configuration proposal
  • Live preview while you map owners
Flexible ownership

Ownership on the asset or on a linked object

Map owners through a user attribute on the asset itself. You can also go through a linked object such as an employee record (Employee -> User). Both resolve server-side with the same default-deny scoping.

  • User attribute or reference path
  • Auto-suggested candidates, including linked-object paths
  • Organization-wide ownership on the roadmap
How it works

Live in three steps

1

Connect your project and asset field

Pick your service desk, request types and the “Assets objects” field. A one-click check verifies the field end to end.

2

Map ownership

Choose the object types customers should see. Confirm the suggested owner attribute, direct or via a linked record. A live preview shows real results as you go.

3

Shape the portal

Set card attributes, status colors, detail views, editability and translations per type. Optionally turn on the dashboard start view. Customers then find “My Assets” in the help center.
