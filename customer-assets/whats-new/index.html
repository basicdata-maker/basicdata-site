What’s new in Customer Assets

Release notes for Customer Assets for the JSM Portal. Updates install automatically through Atlassian Forge.

  1. November 10, 2026

    3.1.0 New name and app icon Latest

    • The app is now called Customer Assets for the JSM Portal.
    • The app has its own icon in Jira administration and in the customer portal menu.
  2. October 27, 2026

    3.0.0 Guided setup and paid plans

    • Paid subscription via Atlassian. New installs start with a 30-day free trial.
    • Setup status panel with four plain-language checks and fix buttons.
    • One-click configuration proposal that scans your site and fills in all four setup steps.
    • Ownership through a linked object, for example Employee -> User.
    • Live preview of your own portal while you map owners.
  3. October 2, 2026

    2.3.0 Maintenance release

    • Improvements and fixes.
  4. September 15, 2026

    2.2.0 Initial Marketplace release

    • “My Assets” view in the customer portal, scoped server-side to the signed-in customer.
    • Asset-linked requests: report a problem, register an asset, request a change, ask a question.
    • Setup wizard with a “Verify field” check for the Assets custom field.
    • English and German UI.

Questions about a release? Open a ticket in our support portal.
